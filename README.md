# 2-INPUT-NAND-GATE
Designed and implemented a 2-input CMOS NAND gate using Cadence Virtuoso and 180 nm technology. The project involved schematic design, transistor-level implementation, simulation, verification, and physical layout of the NAND gate.

Performed DC analysis and transient analysis to evaluate the voltage transfer characteristics, switching behavior, propagation delay, rise time, and fall time. The design was verified for all possible combinations of the two input signals to ensure correct NAND logic functionality.

The physical layout was developed following CMOS design rules and subsequently verified using DRC and LVS checks. Pre-layout and post-layout simulations were performed to analyze the impact of parasitic effects on circuit performance. The final design was used to generate the GDSII file, completing the front-end and back-end VLSI design flow.

This project provided practical experience in CMOS circuit design, Cadence Virtuoso, transistor sizing, simulation, layout design, DRC, LVS, parasitic analysis, post-layout verification, and GDSII generation.
